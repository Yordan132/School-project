# План и решения

Одобрен обхват: универсална система с React + Vite, JavaScript, CSS, симулирани данни за поне три бизнеса. Интерфейс и документация на български. Малки компоненти, отделни функции, без сървър.

1. Общ модел и тестове: бизнес, ресурс, дата, начало/край в минути, заети места. Конфигурация за работни дни, интервали, стъпка и продължителности.
2. Интерфейс: избор на бизнес/дата/ресурс, наличност, създаване, промяна, отказ, localStorage и възстановяване на примерните данни.
3. Проверки: автоматични тестове за граници и капацитет, production build, проверка на потребителския поток.
4. README и ръководство за представяне, записване в GitHub на всеки завършен етап.

Решения: един ресурс на резервация; интервали в рамките на деня; локален календар без часови зони; края на интервала е изключен. Това позволява 10:00–11:00 и 11:00–12:00. Капацитетът е едновременно заетото количество, а не общият сбор на всички пресичащи се резервации. Нов бизнес се добавя като обект в конфигурацията.

Сложността се ограничава чрез индекс по бизнес/ресурс/дата и профил на заетостта на равни времеви стъпки. Профилът се изчислява веднъж за избрания ресурс и ден, след което се използва за всички слотове. Използва се useMemo; няма глобална библиотека за състояние.

Разработка: в чисто клонирано хранилище. Потребителят изрично разреши записване в посочения GitHub repository. Историята отразява реалните етапи, без приписване на commits на други участници.

## Разширение: клиентски и администраторски панел

Изрично избрано от потребителя: демо профили (прост код) и хотели с нощувки. Три отдела с по три ресурса. Клиентът вижда и управлява само свои резервации; admin вижда всички клиенти, включително без записи, филтрира и управлява резервациите. Защитеният Vercel preview запазва съществуващата защита с вход.

Използваме `customerId`, отделен модул за права и действия, режим `hours`/`nights` в конфигурацията, отделна функция за хотелска заетост. Старият localStorage ключ v1 се запазва непокътнат; v2 съдържа записи с познат собственик. Примерни хотели: градски, SPA и планински; лекари: кардиолог, дерматолог и педиатър. Максимален престой 30 нощувки, капацитет в стаи.
