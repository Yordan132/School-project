# Проверки

- `npm test`: часови конфликти, капацитет, съседни интервали, редакция, работно време, алтернативни часове и хотелски варианти, валидни примерни данни, собственост, хотелски нощувки и localStorage.
- `npm run test:e2e`: реален Chromium; двама клиенти и admin, чужди записи не се виждат, редакция и отказ, admin филтри, хотелска наличност по вид стая, избор на предложена алтернатива, търсене на час в следващ работен ден, mobile layout и запазване на темата.
- `npm run build`: production пакет.
- Визуален преглед на клиентски, хотелски и администраторски панел на 390 и 1440 px ширина, в тъмна и светла тема.

След опростяването: **27 unit теста и 7 браузърни теста са успешни**; production build е успешен. `npm audit` отчита 0 известни уязвимости с Vite 6.4.6.

Допълнително са проверени:

- Невалиден запис не презаписва оригиналните данни. Отказът на потвърждението за reset също ги запазва; потвърденият reset възстановява работата.
- Стара хотелска резервация без вид стая сменя датите и запазва шестте си стаи след презареждане.
- Предложенията спират при три намерени варианта и използват индекса по хотел.
- Браузърните сценарии с фиксирани дати използват фиксиран часовник, за да не се сблъскват с примерните записи за днешния ден.

При отделна синтетична проверка с 1000 хотела и 50 000 валидни, неприпокриващи се престоя търсенето на три хотелски предложения обхожда 50 800 записа вместо 100 650 000 преди поправката. Това измерва търсенето с готов индекс, а не зареждането или производителността на цялото приложение.

Демо профилите не са сигурна автентикация. Тестовете доказват поведението на учебния интерфейс и функциите, не защита от потребител, който променя JavaScript или localStorage. Няма синхронизация или многопотребителски сървър.
