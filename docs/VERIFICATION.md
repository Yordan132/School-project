# Проверки на завършения проект

- `npm test`: тестове за припокриване, съседни интервали, точен капацитет, редакция, почивки, невалидни дати/количества, изолация на индекса и слотове.
- Допълнителни проверки: примерни данни при нов бизнес с капацитет 2 и кратък работен прозорец; условията за конфигурациите; празни/повредени запазени данни и отказан запис.
- `npm run test:e2e`: реален Chromium — създаване, презареждане, редакция без промяна, преместване, отказ, групова резервация, изчерпан капацитет, филтър, почивен ден и мобилна ширина. Следят се JavaScript грешките в страницата.
- `npm run build`: production пакет.
- Визуално проверени desktop и mobile снимки от браузърния тест.

При независим преглед беше намерен дефект в генератора на примерните данни за нови конфигурации. Добавен е тест, който първо възпроизведе проблема, след което генераторът бе поправен да избира валидни слотове и количество до капацитета. Ограниченията на времевата стъпка са описани в README и покрити с тест за включените конфигурации.

Няма публикуван хостван сайт. Стартирането е локално през Vite. Тестовете не доказват многопотребителска конкурентност; приложението няма сървър.
