# Проверки

- `npm test`: часови конфликти, капацитет, съседни интервали, редакция, работно време, валидни примерни данни, собственост и забрана за чужда редакция/отказ, запазване на собственик, хотелски нощувки и изчерпан капацитет, локално съхранение.
- `npm run test:e2e`: реален Chromium; двама клиенти и admin, чужди записи не се виждат, чуждите часове остават заети, reload, редакция и отказ, списък с всички клиенти, admin филтри, резервация на всички хотелски стаи, съседно настаняване, редакция от admin, mobile layout, запазване на темата.
- `npm run build`: production пакет.
- Визуален преглед на клиентски и администраторски панел на 390 px ширина.

Демо профилите не са сигурна автентикация. Тестовете доказват поведението на учебния интерфейс и функциите, не защита от потребител, който променя JavaScript или localStorage. Няма синхронизация или многопотребителски сървър.
