# Проверки

- `npm test`: часови конфликти, капацитет, съседни интервали, редакция, работно време, алтернативни часове и хотелски варианти, валидни примерни данни, собственост, хотелски нощувки и localStorage.
- `npm run test:e2e`: реален Chromium; двама клиенти и admin, чужди записи не се виждат, редакция и отказ, admin филтри, хотелска наличност по вид стая, избор на предложена алтернатива, търсене на час в следващ работен ден, mobile layout и запазване на темата.
- `npm run build`: production пакет.
- Визуален преглед на клиентски и администраторски панел на 390 px ширина.

Демо профилите не са сигурна автентикация. Тестовете доказват поведението на учебния интерфейс и функциите, не защита от потребител, който променя JavaScript или localStorage. Няма синхронизация или многопотребителски сървър.
