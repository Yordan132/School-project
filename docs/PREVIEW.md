# Частен преглед на телефона

Адрес: https://myasto-private-preview-cgwycdr9s-dancho4.vercel.app

Изисква вход със собствения Vercel акаунт. Проектът е в екип Dancho, който при създаването има само един член — собственика. Включена е Vercel Authentication (`all_except_custom_domains`); няма добавени собствени домейни. Непотвърден посетител се пренасочва към Vercel SSO.

Това е защитено хоствано копие за преглед, не публичен сайт. Тази версия е Vercel staging deployment и остава защитена с вход, включително vercel.app адресите. Не е конфигурирано автоматично публикуване при GitHub push.

Копието е от commit `1e450bc` с опростен код и обновен дизайн на OnePlace, клиентски и администраторски панел, три отдела, хотелски видове стаи и алтернативни предложения за резервации. Използван е локално провереният Vite build. Следващи промени в GitHub не обновяват този preview автоматично.

Резервациите остават в браузъра на съответното устройство.

Входът във Vercel защитава достъпа до preview. Изборът на клиент/Admin вътре в приложението е учебна демонстрация, а не допълнителна автентикация.
