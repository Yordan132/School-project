# Частен преглед на телефона

Адрес: https://myasto-private-preview-7g3pzapjg-dancho4.vercel.app

Изисква вход със собствения Vercel акаунт. Проектът е в екип Dancho, който при създаването има само един член — собственика. Включена е Vercel Authentication (`all_except_custom_domains`); няма добавени собствени домейни. Непотвърден посетител се пренасочва към Vercel SSO.

Това е защитено хоствано копие за преглед, не публичен сайт. Vercel маркира първото качване като production, но то остава защитено с вход, включително vercel.app адресите. Не е конфигурирано автоматично публикуване при GitHub push.

Копието е от commit `1666cf0f60cedb64dd6f694ec8480179c446b5dd` с тъмната тема. Използван е локално провереният Vite build. Следващи промени в GitHub не обновяват този preview автоматично.

Резервациите остават в браузъра на съответното устройство.
